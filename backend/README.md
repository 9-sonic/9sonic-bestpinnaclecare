# Backend API & Automation

**Expected stack: Ruby on Rails.**

API and jobs: auth, shift scheduling, clock events, late/missed alert engine, timesheet calculation, SMS escalation (later).

This folder starts empty of application code. Scaffold the Rails app here via a PR linked to a backlog issue (typically M3 and related Must items).

UK hosting and compliance are tracked under issue **M3**. Shared API shapes live in `/contracts`.
